IMPORTANT: DOUBLE CLICK run.bat TO START.
There're several coding files and several updating files. These updating files are used for telling AI
how to make this game, not for players to learn the rule because of some mistakes that might be concluded. The rules
are mostly the same with traditional Tetris, so it's easy to learn the rules with playing this game directly.
Press these difficulties below "开始游戏" can preset the speed and the special blocks which may not appear before.
Press "选择特殊方块" can choose whether a specific block can appear in this game.

I'd like to introduce 2 special blocks which might be creative:
1. bomb: Clear 5*5 blocks, each destroy offer 2 points.
2. pepper: Clear 3*10 blocks, each destroy offer 2 points.

Then how to calculate the score:
1. When a line is cleared, +25
2. When ending, each single block on the spot, each +1
3. Bomb and pepper offer points when destroying blocks, each +2
